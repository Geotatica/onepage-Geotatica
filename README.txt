PUBLICAÇÃO NO GITHUB PAGES

1. Crie ou abra o repositório que vai hospedar a one page.
2. Envie estes 3 arquivos para a RAIZ do repositório:
   - index.html
   - logo-geotatica.png
   - danielle-perfil.jpg
3. No GitHub, vá em Settings > Pages.
4. Em Build and deployment, selecione:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /root
5. Salve.
6. Aguarde 1 a 5 minutos.
7. A URL correta normalmente será:
   https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/

CHECKLIST RÁPIDO
- O arquivo principal precisa se chamar exatamente index.html
- O index.html precisa estar na raiz publicada
- O nome do repositório e a URL precisam bater exatamente
- GitHub Pages diferencia maiúsculas e minúsculas na URL
- Se o repositório for onepage-geotatica, use /onepage-geotatica/ e não /onepage-Geotatica/
